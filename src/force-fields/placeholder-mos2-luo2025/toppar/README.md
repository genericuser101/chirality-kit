# placeholder-mos2-luo2025

Rough placeholder parameters for molybdenum disulfide nanotube geometry support.

Source context: Luo et al., *Symmetry-broken MoS2 nanotubes through sequential
sulfurization of MoO2 nanowires*, Nature Communications 16 (2025).

This folder is intentionally minimal. It records chemical elements, masses,
zero charges, zero LJ placeholders, and a rough Mo-S bond distance of
2.4100 Angstrom. It is not a validated production molecular mechanics
parameterization.
