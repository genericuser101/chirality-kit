# placeholder-mosse-rough2026

Rough placeholder parameters for Janus molybdenum sulfur selenide nanotube
geometry support.

Source context: Guerrero-Sanchez et al., *Recent progress on Janus MoSSe for
photocatalytic applications*, Physical Chemistry Chemical Physics 28 (2026)
5629-5639, and Otero-de-la-Roza et al., *Comprehensive determination of highly
symmetric transition metal dichalcogenide multilayers*, Nanoscale 17 (2025).

This folder is intentionally minimal. It records chemical elements, masses,
zero charges, zero LJ placeholders, and rough Mo-S and Mo-Se bond distances of
2.4100 and 2.5200 Angstrom. It is not a validated production molecular
mechanics parameterization.
